# Astra Studio – Design Agency Homepage

A modern and responsive **Design Agency Landing Page** built with **Next.js, TypeScript, and Tailwind CSS**.  
This project focuses on creating a premium UI/UX experience with clean layouts, glassmorphism effects, smooth animations, and responsive design.

## Features
- Modern responsive landing page
- Premium dark-themed UI
- Hero section with creative visuals
- Services showcase
- Portfolio section with project previews
- Contact section
- Smooth hover effects & transitions
- Glassmorphism styling
- Mobile-friendly design

## Tech Stack
- Next.js
- TypeScript
- Tailwind CSS
- React

## Folder Structure
app/
components/
public/
styles/

- npm install
- npm run dev
